简介

平台概览

欢迎使用 APIWebSit — 您的尖端 AI 开发者工具中央文档门户。

本平台提供当今两款最强大 AI 开发平台的全面 API 参考、实施指南和最佳实践：Anthropic 的 Claude Code 和 Nous Research 的 Hermes Agent。

无论您是在构建智能编码工作流、将大语言模型集成到您的应用程序中，还是探索自我改进 AI 代理的前沿领域，本文档都将帮助您快速上手并高效使用这些工具。

新手上路？ 从每个平台的快速开始指南入手。它们将引导您在五分钟内完成安装、身份验证和首次交互式会话。

Claude Code

Anthropic 的智能编码工具 — 驻留在您终端中的 AI 队友。

快速开始

在两分钟内让 Claude Code 运行起来。您需要一个终端和一个 Anthropic API 密钥。

1. 安装 Claude Code

在终端中运行官方安装程序：

# Install
curl -fsSL https://claude.ai/install.sh | bash

2. 设置您的 API 密钥

Claude Code 使用 ANTHROPIC_API_KEY 环境变量进行身份验证：

# Set API key
export ANTHROPIC_API_KEY="sk-ant-..."

3. 开始编码

导航到您的项目目录并启动 Claude Code：

# Start coding
cd my-project
claude

大功告成。Claude Code 将分析您的项目结构并呈现一个交互式 REPL 会话。尝试让它解释文件、编写函数或调试问题。

专业提示： 您也可以使用 claude -p "your prompt" 进行一次性查询，无需进入交互式会话 — 非常适合 CI/CD 流水线和快速提问。

安装指南

Claude Code 支持跨平台的多种安装方式。选择最适合您环境的方法：

平台 命令
macOS / Linux / WSL curl -fsSL https://claude.ai/install.sh | bash
Windows (PowerShell) irm https://claude.ai/install.ps1 | iex
macOS (Homebrew) brew install --cask claude-code
npm（旧版） npm install -g @anthropic-ai/claude-code

安装后，运行 claude doctor 验证一切是否正常工作，该命令会对您的环境执行诊断健康检查： 

claude doctor

配置说明

Claude Code 使用分层配置系统。设置按以下层级从高到低优先级解析：

  1. 会话标志 — 诸如 --model 和 --allowedTools 之类的 CLI 参数
  2. 项目级设置 — 当前项目中的 .claude/settings.json
  3. 主目录设置 — ~/.claude/settings.json
  4. 全局配置 — 通过 claude config set -g 设置
  5. 默认值 — Claude Code 内置默认值

以下是项目级 settings.json 的示例： 

{
  "model": "claude-sonnet-4-6",
  "permissions": {
    "allowedTools": ["Read", "Write", "Bash(*)"]
  },
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Write(*.py)",
        "hooks": [
          {
            "type": "command",
            "command": "python -m black $file"
          }
        ]
      }
    ]
  }
}

API 参考

Claude Code 基于 Anthropic Messages API 构建。您可以直接集成该 API，围绕 Claude 构建自定义工具和工作流。

Messages API

Messages API 允许您向 Claude 发送对话并接收流式或非流式响应。以下是 Python 和 JavaScript 的示例：

Python（使用 Anthropic SDK）

import anthropic

client = anthropic.Anthropic(
    api_key="sk-ant-..."
)

response = client.messages.create(
    model="claude-sonnet-4-6",
    max_tokens=1024,
    messages=[{"role": "user", "content": "Hello, Claude!"}]
)

print(response.content[0].text)

JavaScript / TypeScript（使用 Anthropic SDK）

import Anthropic from '@anthropic-ai/sdk';

const client = new Anthropic({
  apiKey: 'sk-ant-...'
});

const response = await client.messages.create({
  model: 'claude-sonnet-4-6',
  max_tokens: 1024,
  messages: [{ role: 'user', content: 'Hello, Claude!' }]
});

console.log(response.content[0].text);

关键参数

参数 类型 描述
model string 模型 ID（例如 claude-sonnet-4-6）
messages array 包含 role 和 content 的消息对象数组
max_tokens integer 响应中的最大令牌数
system string 用于上下文的系统提示
temperature float 采样温度（0.0 - 1.0）
stream boolean 启用流式响应

Hermes Agent

Nous Research 的开源、自我改进 AI 代理 — 灵活、提供商无关且可扩展。

快速开始

快速启动 Hermes Agent。Hermes 支持广泛的 LLM 提供商，让您可以轻松使用自己喜欢的模型。

1. 安装 Hermes

# Install
curl -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh | bash

2. 运行设置向导

交互式设置向导将引导您选择提供商、设置 API 密钥以及配置模型：

# Run setup wizard
hermes setup

3. 开始对话

使用您配置的模型启动交互式聊天会话：

# Start chatting
hermes
设计上无供应商依赖： Hermes 支持 20 多个提供商，包括 Anthropic、OpenAI、DeepSeek、Google Gemini、Ollama 和 LM Studio。随时使用 hermes model 切换提供商。

安装指南

Hermes Agent 提供多种安装方式，以适应不同的环境：

方法 命令 / 说明
快速安装 curl -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh | bash
pip pip install hermes-agent
Railway 从 railway.com 一键部署
Docker docker pull nousresearch/hermes-agent

所有安装方式都提供相同的核心功能。对于希望与现有 Python 项目紧密集成的 Python 开发者，建议使用 pip 安装。

配置说明

Hermes 将其配置存储在 ~/.hermes/config.yaml 中。配置基于 YAML 并按部分组织。

配置文件结构

# ~/.hermes/config.yaml
model:
  provider: "openrouter"
  default: "anthropic/claude-opus-4.6"
  base_url: "https://openrouter.ai/api/v1"

tools:
  enabled:
    - web_search
    - code_interpreter
    - file_system

agent:
  max_turns: 50
  temperature: 0.7

配置命令

Hermes 提供多个用于管理配置的命令：

命令 描述
hermes setup 初始设置的交互式向导
hermes model 快速切换模型和提供商
hermes config edit 在默认编辑器中打开配置文件
hermes config set model.provider openrouter 使用点符号设置单个配置值

提供商

Hermes 支持 20 多个 LLM 提供商，为您提供灵活性，以便为您的特定用例使用最佳模型。以下是最常用的提供商：

提供商 配置键 认证方式
Nous Portal nous NOUS_API_KEY
OpenRouter openrouter OPENROUTER_API_KEY
Anthropic anthropic ANTHROPIC_API_KEY
OpenAI openai OPENAI_API_KEY
DeepSeek deepseek DEEPSEEK_API_KEY
Google Gemini gemini GOOGLE_API_KEY
AWS Bedrock bedrock IAM 认证
Ollama（本地） ollama http://localhost:11434
LM Studio（本地） lmstudio 本地端点

提供商配置示例

OpenRouter

# OpenRouter
hermes config set model.provider openrouter
hermes config set model.base_url https://openrouter.ai/api/v1

DeepSeek

# DeepSeek
hermes config set model.provider deepseek
hermes config set model.default deepseek-v4-pro

Ollama（本地）

# Ollama (local)
hermes config set model.provider ollama
hermes config set model.base_url http://localhost:11434

本地设置的 YAML 配置

model:
  provider: "ollama"
  default: "llama3-70b"
  base_url: "http://localhost:11434"

tools:
  enabled:
    - code_interpreter
    - web_search
