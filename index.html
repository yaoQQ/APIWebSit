Introduction

Platform Overview

Welcome to APIWebSit — your central documentation portal for cutting-edge AI developer tools.

This platform provides comprehensive API references, implementation guides, and best practices for two of the most powerful AI development platforms available today: Claude Code by Anthropic and Hermes Agent by Nous Research.

Whether you are building agentic coding workflows, integrating large language models into your application, or exploring the frontier of self-improving AI agents, this documentation will help you get started quickly and use these tools effectively.

New here? Start with the Quickstart guides for each platform. They walk you through installation, authentication, and your first interactive session in under five minutes.

Ecosystem

The AI development landscape is evolving rapidly. APIWebSit focuses on two complementary platforms that represent different approaches to AI-assisted development:

Anthropic

Claude Code

Anthropic's agentic CLI tool for AI-assisted software development. Deeply integrated with the Claude API ecosystem, Claude Code operates as an autonomous coding assistant directly in your terminal — reading files, writing code, running commands, and managing complex multi-step development workflows.

Nous Research

Hermes Agent

An open-source, self-improving AI agent framework supporting 400+ models across 20+ providers. Hermes focuses on flexibility and provider-agnostic design, allowing you to switch between Anthropic, OpenAI, DeepSeek, local models, and more with a single configuration change.

Both platforms support MCP (Model Context Protocol) servers, tool use, and extensible plugin architectures, but they differ in their primary use cases and deployment models:

Claude Code

Anthropic's agentic coding tool — an AI teammate that lives in your terminal.

Quickstart

Get Claude Code running in under two minutes. You'll need a terminal and an Anthropic API key.

1. Install Claude Code

Run the official installer in your terminal:

# Install
curl -fsSL https://claude.ai/install.sh | bash

2. Set your API key

Claude Code authenticates using the ANTHROPIC_API_KEY environment variable:

# Set API key
export ANTHROPIC_API_KEY="sk-ant-..."

3. Start coding

Navigate to your project directory and launch Claude Code:

# Start coding
cd my-project
claude

That's it. Claude Code will analyze your project structure and present an interactive REPL session. Try asking it to explain a file, write a function, or debug an issue.

Pro tip: You can also use claude -p "your prompt" for one-shot queries without entering the interactive session — perfect for CI/CD pipelines and quick questions.

Installation

Claude Code supports multiple installation methods across platforms. Choose the one that works best for your environment:

Platform Command
macOS / Linux / WSL curl -fsSL https://claude.ai/install.sh | bash
Windows (PowerShell) irm https://claude.ai/install.ps1 | iex
macOS (Homebrew) brew install --cask claude-code
npm (legacy) npm install -g @anthropic-ai/claude-code

After installation, verify everything is working by running claude doctor, which performs a diagnostic health check on your environment: 

claude doctor

Configuration

Claude Code uses a layered configuration system. Settings are resolved from highest to lowest priority in the following hierarchy:

  1. Session flags — CLI arguments like --model and --allowedTools
  2. Project-level settings — .claude/settings.json in the current project
  3. Home directory settings — ~/.claude/settings.json
  4. Global configuration — set via claude config set -g
  5. Defaults — built-in Claude Code defaults

Here is an example project-level settings.json: 

{
  "model": "claude-sonnet-4-6",
  "permissions": {
    "allowedTools": ["Read", "Write", "Bash(*)"]
  },
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Write(*.py)",
        "hooks": [
          {
            "type": "command",
            "command": "python -m black $file"
          }
        ]
      }
    ]
  }
}

API Reference

Claude Code is built on the Anthropic Messages API. You can integrate directly with the API to build custom tooling and workflows around Claude.

Messages API

The Messages API allows you to send conversations to Claude and receive streaming or non-streaming responses. Here are examples in Python and JavaScript:

Python (using the Anthropic SDK)

import anthropic

client = anthropic.Anthropic(
    api_key="sk-ant-..."
)

response = client.messages.create(
    model="claude-sonnet-4-6",
    max_tokens=1024,
    messages=[{"role": "user", "content": "Hello, Claude!"}]
)

print(response.content[0].text)

JavaScript / TypeScript (using the Anthropic SDK)

import Anthropic from '@anthropic-ai/sdk';

const client = new Anthropic({
  apiKey: 'sk-ant-...'
});

const response = await client.messages.create({
  model: 'claude-sonnet-4-6',
  max_tokens: 1024,
  messages: [{ role: 'user', content: 'Hello, Claude!' }]
});

console.log(response.content[0].text);

Key Parameters

Parameter Type Description
model string The model ID (e.g., claude-sonnet-4-6)
messages array Array of message objects with role and content
max_tokens integer Maximum tokens in the response
system string System prompt for context
temperature float Sampling temperature (0.0 - 1.0)
stream boolean Enable streaming response

Hermes Agent

Nous Research's open-source, self-improving AI agent — flexible, provider-agnostic, and extensible.

Quickstart

Get Hermes Agent running quickly. Hermes supports a wide range of LLM providers, making it easy to use whatever model you prefer.

1. Install Hermes

# Install
curl -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh | bash

2. Run the setup wizard

The interactive setup wizard will guide you through choosing a provider, setting your API key, and configuring your model:

# Run setup wizard
hermes setup

3. Start chatting

Launch an interactive chat session with your configured model:

# Start chatting
hermes
Provider-agnostic by design: Hermes supports 20+ providers including Anthropic, OpenAI, DeepSeek, Google Gemini, Ollama, and LM Studio. Switch providers anytime with hermes model.

Installation

Hermes Agent offers multiple installation methods to suit different environments:

Method Command / Instructions
Quick Install curl -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh | bash
pip pip install hermes-agent
Railway One-click deploy from railway.com
Docker docker pull nousresearch/hermes-agent

All installation methods provide the same core functionality. The pip installation is recommended for Python developers who want tight integration with existing Python projects.

Configuration

Hermes stores its configuration in ~/.hermes/config.yaml. The configuration is YAML-based and organized by section.

Config File Structure

# ~/.hermes/config.yaml
model:
  provider: "openrouter"
  default: "anthropic/claude-opus-4.6"
  base_url: "https://openrouter.ai/api/v1"

tools:
  enabled:
    - web_search
    - code_interpreter
    - file_system

agent:
  max_turns: 50
  temperature: 0.7

Configuration Commands

Hermes provides several commands for managing configuration:

Command Description
hermes setup Interactive wizard for initial setup
hermes model Quickly switch model and provider
hermes config edit Open config file in default editor
hermes config set model.provider openrouter Set individual config values with dot notation

Providers

Hermes supports over 20 LLM providers, giving you the flexibility to use the best model for your specific use case. Here are the most commonly used providers:

Provider Config Key Auth Method
Nous Portal nous NOUS_API_KEY
OpenRouter openrouter OPENROUTER_API_KEY
Anthropic anthropic ANTHROPIC_API_KEY
OpenAI openai OPENAI_API_KEY
DeepSeek deepseek DEEPSEEK_API_KEY
Google Gemini gemini GOOGLE_API_KEY
AWS Bedrock bedrock IAM auth
Ollama (local) ollama http://localhost:11434
LM Studio (local) lmstudio Local endpoint

Provider Configuration Examples

OpenRouter

# OpenRouter
hermes config set model.provider openrouter
hermes config set model.base_url https://openrouter.ai/api/v1

DeepSeek

# DeepSeek
hermes config set model.provider deepseek
hermes config set model.default deepseek-v4-pro

Ollama (local)

# Ollama (local)
hermes config set model.provider ollama
hermes config set model.base_url http://localhost:11434

YAML Configuration for a local setup

model:
  provider: "ollama"
  default: "llama3-70b"
  base_url: "http://localhost:11434"

tools:
  enabled:
    - code_interpreter
    - web_search
